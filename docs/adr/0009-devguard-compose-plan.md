# DevGuard compose plan (ratified 2026-09-18)

The stakeholder ratified the four open service-plan decisions: (1) the orchestrator joins the existing open-webui_default network rather than getting a new bridge to OWUI; (2) the DevGuard service table deploys as proposed (postgresql, kratos, api, web, dependency proxy) with a dedicated devguard-egress network for upstream registry access; (3) the dependency proxy is internal-only — no LAN port published, reachable solely from the runners and orchestrator networks; (4) dependencyProxyCache is sized at 2048 MB against the host's free disk. The internal-only choice is the load-bearing one: it keeps DevGuard's only clients on internal networks, so the zero-egress invariant is preserved by network position, and it removes any temptation to bypass the proxy from outside the fleet.
